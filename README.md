## Funcionalidades

- Play / Pause com icone animado
- Barra de progresso clicavel (arrastar ou clicar para pular)
- Timer com tempo atual e duracao total calculados automaticamente
- Botoes de avancar e voltar 10 segundos
- Capa do album gira durante a reproducao
- Reset automatico ao terminar a musica
- Design neumorfismo com sombras e transicoes
- Layout responsivo (desktop e mobile)

## Tecnologias

- HTML5 + Audio API
- CSS3 (Neumorfismo, Flexbox, Animacoes)
- JavaScript Vanilla
- Font Awesome (icones)
- Material Icons (skip buttons)
- Google Fonts (Raleway)

## Como rodar

Basta abrir o `index.html` no navegador.
